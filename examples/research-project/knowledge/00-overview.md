# Overview

This research example keeps a claim and its source paper in one bounded project.

## Follow the evidence

Open the [reproducibility claim][claim], then follow its reference to the [source study][study]. The Human View shows readable notes, while Graph View exposes the declared import and the reference actually used in the claim.

## Inspect agent context

In Agent View, choose Reproducibility Claim and ask `What evidence supports reproducibility?` to inspect the selected documents, traversal path, and token cost.
