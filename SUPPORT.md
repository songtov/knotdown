# Support

Knotdown is alpha software.

- Use a GitHub Discussion for questions, examples, and workflow ideas once Discussions is enabled.
- Use the bug report form for reproducible defects.
- Use the feature request form for scoped proposals.
- Use the private security reporting path described in [SECURITY.md](SECURITY.md) for vulnerabilities.

Please share a minimal synthetic project instead of private vault contents. Remove absolute paths, credentials, and personal identifiers before posting.
